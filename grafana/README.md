# Grafana dashboards

- `user-activity.json` — **trix — активність користувачів**: DAU (any activity) and what people did
  per day, WAU/MAU and stickiness, feature adoption over 30 days, workouts/check-ins/signups/events
  per day, retention by signup week (weeks 1/2/4/8), the most used bot/app actions and the most
  active users. Data: `GET /admin/metrics/activity?days=N` (7–90).

Generated by `scripts/build-grafana-activity.mjs`; edit the script, not the JSON.

## Upload

The panels read the Worker through the **Infinity** datasource. Its settings need the
`X-Admin-Secret` header (the Worker's `ADMIN_SECRET`) and the Worker's host in *Allowed hosts* —
the same setup the owner metrics board uses. Then:

```sh
GRAFANA_URL=https://<stack>.grafana.net GRAFANA_TOKEN=<service account token> \
WORKER_URL=https://<your-worker>.workers.dev node scripts/grafana-push.mjs
```

Or import the JSON by hand (Dashboards → New → Import) and pick the Infinity datasource and
Worker URL in the variables at the top.
